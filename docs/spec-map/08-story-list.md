  - 訂正:

- **LIST-08b** ⚠★★★**④の条件は「差分が何を見つけたか」であって、カウンターが何と言ったかではない**

- **LIST-09** ★**2種類以上が動いていたら `+` が付く**（`Ruby+` `Text+`）。
  ⇒ **語は最初の1つを名乗り、記号が「他にもある」と言う。**

- **LIST-10** ⚠**`None` は「変更なし」ではない。** カウンターは動いている（でなければ行は建たない）ので、

## 5. クリックすると何が起きるか

- **LIST-24** ★**シングルクリック（親）＝そのストーリーの最初のフレームを、Target の窓の中央に出す。**
  - 訂正:

- **LIST-25** ★★**Source の窓も一緒に動く。ただし「同じページ番号」ではなく「同じストーリー」を狙う。**
  ⇒ 2つの版でストーリーの居場所が違っても、ちゃんと同じ文を見せる。
  （⚠Prev/Next は**ページ**で合わせる ―― あちらが歩いているのはページだから。第12章／第14章）
  - 訂正:

- **LIST-26** ★**シングルクリック（子）＝その変更の場所へ行き、そこに印を一瞬灯す**（約1秒で消える）。
  ★★**選択ではなく印**（2026-08-20 の作者の指定）＝選択にすると
  ①読み手が選んでいたものが消え ②文字ツールに切り替わり ③見終わった後も選ばれたまま になるため。
  ★印は**文字に直接描く公式の仕組み**（global text adornment）なので、縦組みでも回転したフレームでも
  座標を計算せずに正しい位置に出て、**文書は1バイトも変わらない**。
  - 訂正:

- **LIST-27** ★**子の行が狙うのは「変更のある場所」であって、ストーリーの先頭ではない。**
  ⇒ 連結したフレームでは、親の行とは別のフレームが中央に来る。
  - 訂正:

- **LIST-28** ★★**古い版の窓も、同じ**変更**の位置まで行く**（2026-08-22 以降）。
  ⚠**古い版の位置は新しい版とは別の数**なので、変更が両側の位置を持っていることが前提（第7章 ST-21）。
  - 訂正:

- **LIST-29** ★**ダブルクリック＝その文字を実際に選択する**（欲しい人はこちら）。
  ★**同時にキーボードが文書へ戻る。**
  - 訂正:

- **LIST-30** ⚠★★**ダブルクリックは4つの出来事として届く**（押す・離す・ダブルクリック・離す）＝
  **最初の「離す」で1回目の動作がもう済んでいる。** ⇒ ダブルクリックの処理を「ダブルクリック」の
  タイミングに書くと、**後から来る「離す」に上書きされる**。
  - 訂正:

- **LIST-31** 右クリック（親）＝**Refresh Story Comparison**（第7章 ST-43）。~~**子の行では何も出ない。**~~
  - 訂正: 2026-09-12 から**子の行（変更1件）にもメニューが出る**＝ LIST-45 / LIST-46。

- **LIST-45** 右クリック（子）＝**Copy Source Text**（2026-09-12）。旧版側の語（ルビの行ならその読み）を
  クリップボードへ。**旧版側が空（挿入・ルビの追加・圏点・脚注の行）なら灰色**。Story モードのみ。
  - 訂正:

- **LIST-46** 右クリック（子）＝**Restore Source Text**（2026-09-13）。**その1件だけ**を旧版の状態に書き戻す
  ＝本文（挿入は取り去る）／ルビ（変更・追加・削除。**モノはモノに、グループはグループに**）／圏点（種類）。
  **1つのコマンド列「Restore Source Text」＝Ctrl+Z 1回**。書いた後は**その行だけ比べ直す**（ST-43 と同じ道）ので
  戻した変更は一覧から消え、残りの位置は取り直される。
  **断る条件（理由はステータス行）**＝①比較の後にそのストーリーが編集された（行の
  `fTargetTextCount` と `ITextModel::GetTextChangeCount` が違う→先に Refresh）②カスタム圏点
  ③本文も変わった段落の属性（新版側の範囲が 0）。実装＝`KCMStoryRestore.cpp`。
  - 訂正:

- **LIST-32** ★**行を押すとキーボードが一覧に来る。** ⚠**これは意図的に反転した決定**（2026-08-11）＝
  それまでは「パネルは読み手を文書へ送り出したら黙る」ため**わざと取らなかった**。
  作者の要望（「KBS のように上下キーで歩きたい」）で反転。
  ★**代償は残っている**（パネルがキーボードを持つ間、ツールのショートカットが効かない）ので、
  **戻る道が2つ**用意されている＝**ダブルクリック**と**文書を直接クリック**。
  - 訂正:
