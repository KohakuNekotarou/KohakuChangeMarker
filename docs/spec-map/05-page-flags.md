## 1. 3つの印は、性格がそれぞれ違う

- **FLG-01** ★★★**この章の3つは見た目が似ているだけで、役割が違う。**
  - **登録（Added / Removed）** ＝ **比較への入力**。「このページには相手がいない」と比較に教える値。
  - **✓（Check）** ＝ 読み手の印。「**このページはもう見た**」。
  - **猫の手スタンプ** ＝ 読み手の印。「**ここを見て**」（場所を指す）。
  - 訂正:

- **FLG-02** ★**違いは扱いに出る。** 登録は比較の一部なので**比較を止めると消える**。
  ✓と猫の手は読み手のものなので**残る**し、**比較していない文書にも置ける**。
  - 訂正:

## 2. 登録（Added / Removed）

- **FLG-03** Pages パネルでページを選び、右クリックの **Register as Added/Removed Pages** で付け外しする
  （選んだ中に未登録が1つでもあれば全部登録、全部登録済みなら全部解除）。
  - 訂正:

- **FLG-04** ★**Target（新しい方）で登録すれば「追加されたページ」、Source（古い方）で登録すれば
  「削除されたページ」。** 同じ操作で、どちらの文書かによって意味が決まる。
  - 訂正:

- **FLG-05** 登録したページは**対応づけから外れる**（第3章 CMP-05）。⇒ 途中でページが増減しても、
  それ以降の組がずれない。
  - 訂正:

- **FLG-06** ⚠**マスターページには付けられない**（メニューに出ない）。マスターは名前で対応づけるので、
  登録しても比較が変わらないため（第3章 CMP-08）。
  - 訂正:

- **FLG-07** 押せるのは**比較中**で、かつ**Target か Source を見ているとき**だけ。第3の文書では灰色。
  - 訂正:

- **FLG-08** ★**Stop で消える。** 比較の入力なので、比較が終われば役目も終わる ――
  別の対で比べ直したときに古い登録が紛れ込まないようにするため。
  - 訂正:

- **FLG-09** **文書には書き込まれない。** セッションの記憶で、文書を閉じれば消える。
  - 訂正:

## 3. ✓（Check）

- **FLG-10** Pages パネルでページを選び、右クリックの **Check** で付け外しする。
  - 訂正:

- **FLG-11** ★★**比較していなくても付けられる**（2026-09-04 の決定）。開いているどの文書のどのページにも置ける。
  - 訂正:

- **FLG-12** ★**どのページにも付けられる。** モードにも、比較しているかどうかにも、そのページに
  マークが出ているかどうかにも、よらない。

    ★**絞る理由がもう無い**＝2026-09-04 に「✓は比較に依存しない」と決めた時点で、この制限だけが

    ⇒ 判定は1行になり、条件分岐そのものが消えた。✅**実機で確認済み**（2026-09-07 夜・作者の手で＝「全頁でチェックがつくようになっていました」）

  ⇒ 比較し直してページのマークが消えても、✓はそのまま残る。

## 4. 猫の手スタンプ

- **FLG-14** ツール（ツールボックスの Kohaku Change Marker ツールを押しっぱなしにすると出るフライアウト、
  またはパネルのツールボタン）で **Kohaku Cat Paw Tool** に切り替えて使う。
  - 訂正:

- **FLG-15** ★**操作は4つ。**
  - **クリック** ＝ いまツールが持っている色で肉球を置く
  - **Alt＋クリック** ＝ 言葉を聞いてから、それを添えた肉球を置く
  - **Shift+Alt＋クリック** ＝ ★**色を入れ替えるだけ**（赤 ⇄ 青）。**肉球は置かれない**
  - **Shift＋クリック** ＝ その場所の肉球を剥がす
  - **Shift＋ダブルクリック** ＝ **そのページの肉球を全部消す**
  - 訂正:

- **FLG-16** ★**色は赤と青の2色**で、赤が既定。★**Kohaku InDesign MCP と同じ2色**で、
  赤は Claude が印を付ける色、青は人の色。
  ⚠**キーで色を「選ぶ」のではなく「入れ替える」**のは、2色を3つの置き方に割り当てられないため。
  - 訂正:

- **FLG-17** **同じ場所に重ねては置けない。**
  - 訂正:

- **FLG-18** ★**比較していなくても使え、Stop でも消えない**（✓と同じ）。
  - 訂正:

- **FLG-19** フライアウトの **Clear Cat Paws in This Document** で、**アクティブドキュメント**の
  肉球だけを消せる（✓は別の項目）。
  - 訂正: ✅2026-09-07 対応 → 「アクティブな文書」を**アクティブドキュメント**に改めた
    （画面に出る説明文のほうも同じ語に揃えた）。★InDesign 自身の日本語 UI が「ドキュメント」なので、
    そちらに合わせるほうが読み手には自然です。⬜**説明文の他の箇所は「文書」のまま**なので、
    全体を「ドキュメント」に統一しますか ―― そうするなら別途まとめて直します

## 5. ★★どこに残るか

- **FLG-20** ★★★**✓と猫の手は、文書のページに書き込まれる**（置いた時点で自動）。
  ⇒ **Ctrl+Z で取り消せる**し、**文書を保存すれば次に開いたときも残っている**。
  - 訂正:

- **FLG-21** ★**この2つだけが例外で、ほかは文書に何も書かない。** 比較のマークも登録も、
  文書には一切触れない。✓と猫の手が例外なのは、**読み手自身が残した仕事**だからで、
  それはファイルと一緒に置いておく価値がある、という判断による（2026-09-07）。
  - 訂正:

- **FLG-22** ⚠**書き込むのは読み手が印を置いたときだけ。** 読み取り（開いたときの復元）は自動だが、
  **書き込みが勝手に起きることはない** ―― 文書を変更済みにする操作なので、
  読み手の行為としてだけ起こり、取り消せる。
  - 訂正:

- **FLG-23** ⚠**このプラグインの印は、専用の名前を付けて保存される。** 同じページに付いている
  読み手自身の（あるいは他のプラグインの）ラベルには触らない ―― 消すときも、
  自分のぶんだけを外して残りはそのまま書き戻す。
  - 訂正:

- **FLG-24** （**削除**。ここには「Save Check & Register / Load Check & Register で、3つとも
  プラグイン専用のファイルに保存・復元できる」と書いてあった。**その2項目ごと無くなった**ので、
  規則そのものが消えた。★番号は詰めない、という決まりに従ってここは空けておく。）
  - 訂正: ✅2026-09-07 対応（**機能を削除**）→ ご指示のとおり、フライアウトの2項目と、
    その裏にあった専用ファイルの読み書き（約320行）を取り除いた。
    ★**理由もそのとおり**＝✓と肉球は文書に自動で書き込まれるので、専用ファイルは**同じものの二重の写し**
    だった。しかも**文書のパスで結びつけていた**ので、移動や別名保存で切れる弱さも抱えていた。
    登録（Added/Removed）は1回の比較のための指定なので、持ち越す値ではない。
    ⚠**2つの ActionID は欠番にした**（読み手が割り当てたショートカットは番号で保存されるため、
    使い回すと別の機能が動いてしまう）。⚠**公開済みの機能なので、次のリリースノートに書く必要がある。**
    ✅ビルド済み（model は 415,232 → 394,240 バイトに減った）
