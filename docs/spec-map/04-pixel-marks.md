## 3. 色と濃さ

- **MK-07** 色は**赤（既定）か シアン**の2択で、**読み手が選ぶ**（フライアウトの Mark colour）。
  - 訂正:

- **MK-08** ★★**かつては自動で決めていた**（赤っぽい地の上では自動でシアンに変えていた）が、**やめた**。
  理由は2つ ―― ①**Story モードの色地は下の地を読めない**ので、2つのモードで色の決まり方が食い違う
  ②**自動で変わると、見ている人にその理由を説明できない**。
  ⇒ **赤が地に紛れるなら、読み手がシアンを選ぶ。**
  - 訂正:

- **MK-09** 濃さは **25% と 75%** の2択（フライアウト）。**画面と印刷で同じ値**を使う。
  - 訂正:

- **MK-10** ★**常に表示しているときも、選んだ濃さで出る**（25% を選んでいれば 25%）。
  ⇒ 目にする濃さは、押している間も常時表示も**同じ値**。
  ★不透明（100%）になる道はあるが、**Print comparison marks も Always Show Marks on Target も OFF のとき**だけで、
  そのときは**そもそも常時表示にならない**（左ボタンを押している間しか出ない）。⇒ **実際には目に入らない値。**
  - 訂正: ✅2026-09-07 回答＋対応 → **ご指摘のとおりで、地図が誤っていた。**
    濃さを決める式は「Print comparison marks **または** Always Show Marks on Target が ON なら選んだ濃さ、
    どちらも OFF なら不透明」。⚠**私はヘッダーのコメントを写したのだが、そのコメントが
    Always Show Marks on Target を落としていた**（コメント側も直した）

## 4. ★★いつ見えるか ―― 印の種類ごとに規則が違う

- **MK-11** **リングとあふれの「/」**が画面に出るのは、次のどれかのとき。
  ① **ツールの左ボタンを押している間**（既定。押すと出て、離すと消える）
  ② **Print comparison marks が ON**（このときは常時表示になる）
  ③ **Always Show Marks on Target が ON**（★**画面だけ**）
  ④ サムネイル（第12章）
  - 訂正:

- **MK-12** ★★★**✓（Check）と猫の手は、この規則に従わない。** どちらも**画面では常に見えている**
  ―― トグルとも、ツールの左ボタンとも無関係。⇒ **「比較の印」と「読み手が残した印」は、見え方からして別物。**
  （それぞれの詳細は第5章。）
  - 訂正:

- **MK-13** **旧版の覗き見（peek）**も左ボタンの規則とは別で、**Shift＋左ボタン**（旧版を不透明で重ねる）と
  **Shift+Alt＋左ボタン**（50% で重ねる）。**押している間だけ**見え、離すと元に戻る。
  ★**Target と Source のどちらの窓からでも働く。** 詳しくは第13章。
  - 訂正: ✅2026-09-07 回答＋対応 → **ご指摘のとおりで、地図が誤っていた。**
    「ダブルクリック」と書いたが、**覗き見の入口にダブルクリックは1か所も無い**（実測0件）。
    ⚠**これもヘッダーのコメントを写したもの**で、そちらが「driven separately, by a double click」と
    書いたまま腐っていた（コメント側も直した）

## 5. Target と Source は対称ではない

- **MK-14** ★★**「Always Show Marks on Target」は画面だけ、「Always Show Marks on Source」は画面と出力の両方。**
  この非対称は意図したもの ―― Target 側の出力は **Print comparison marks** が決めると決めてあるので、
  Target 側の常時表示が出力にも効いてしまうと、**Print comparison marks が意味を失う**。
  - 訂正: ✅2026-09-07 回答 → **はい、いまは出力にも出ます**（実装で確認＝印刷のときは Source 側のトグルだけで決まり、
    Print comparison marks を見ていない）。⬜**「画面だけに」する変更はご返事待ち。**
    ★変えると失われるのは「**旧版のほうにマークを付けて刷る／PDF にする**」という道で、それを使う場面が
    無ければ、Target と同じ規則（出力は Print comparison marks が決める）に揃うぶん分かりやすくなります

- **MK-15** ⚠Source 側の常時表示は、**オーバープリントプレビュー中も隠れない**。
  - 訂正: ⬜2026-09-07 保留 → MK-14 と同じ変更の一部（「画面だけにする」なら、
    オーバープリントプレビュー中は隠れ、Print comparison marks が ON のときだけ出る、という形になる）。
    ⚠**この項目は実装をまだ読み直していない**（オーバープリント時の分岐そのものを見ていない）ので、
    MK-14 に手を入れるときに一緒に確かめます

- **MK-16** ★どちらのトグルも **Start は触らない**。設定はパネルと一緒に保存され、起動時に戻るので、
  比較のたびに上書きすると**保存した選択が消えてしまう**ため。
  - 訂正:

  ―― これらは**ページの対応づけ**から来るもので、対応づけは**どちらのモードでも作られる**から。
  - 訂正:

- **MK-18** （**削除**。実装の書き方についての注意でしかなく、製品の決まりごとではなかった。
  言いたかったことは MK-17 に入っている。★番号は詰めない、という決まりに従ってここは空けておく。）
  - 訂正: ✅2026-09-07 対応 → **「これ何をいってるの？」というご指摘のとおり、読み手に意味のない項目だった。**
    「描画のコードは Story モードでも入口で引き返してはいけない」という**実装者向けの注意**を、
    そのまま規則として書いてしまっていた。⇒ 削除。★**この地図は「製品として何がどう決まっているか」を

## 7. ノンブルを除外した領域の網

- **MK-19** 「Ignore Page Number Marker」が ON のとき、**比較から外した矩形が緑で塗られる**
  （不透明度 35%）。⇒ **どこを見なかったか**が画面で分かる。
  ⚠**実装は面の塗りつぶし**で、枠線は引いていない（`rectfill` 1本）。
  - 訂正: ✅2026-09-07 回答 → 呼び方を「網」から改めた。**実装は塗りつぶし**なので、
    見えているものも面のはず。⬜**濃さを 35% → 25% にする件は、ご返事を待って別途**
    （コードの定数を1つ変えるだけ）。★もし画面で「枠」に見えているなら、それは
    塗りとは別の何かを見ている可能性があるので、そのときは知らせてください

- **MK-20** ★その塗りは、**その比較が実際に使った矩形**そのもの（第3章 CMP-21）。
  - 訂正: ✅2026-09-07 対応 → 「網」を「塗り」に直した（MK-19 と同じ）
