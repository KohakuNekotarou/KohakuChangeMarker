## 3. 色と濃さ

- **MK-07** 色は**赤（既定）か シアン**の2択で、**読み手が選ぶ**（フライアウトの Mark colour）。
  - 訂正:

- **MK-08** ★★**かつては自動で決めていた**（赤っぽい地の上では自動でシアンに変えていた）が、**やめた**。
  理由は2つ ―― ①**Story モードの色地は下の地を読めない**ので、2つのモードで色の決まり方が食い違う
  ②**自動で変わると、見ている人にその理由を説明できない**。
  ⇒ **赤が地に紛れるなら、読み手がシアンを選ぶ。**
  - 訂正:

- **MK-09** 濃さは **25% と 75%** の2択（フライアウト）。**画面と印刷で同じ値**を使う。
  - 訂正:

- **MK-10** ★**常に表示しているときも、選んだ濃さで出る**（25% を選んでいれば 25%）。
  ⇒ 目にする濃さは、押している間も常時表示も**同じ値**。
  ★不透明（100%）になる道はあるが、**Print comparison marks も Always Show Marks on Target も OFF のとき**だけで、
  そのときは**そもそも常時表示にならない**（左ボタンを押している間しか出ない）。⇒ **実際には目に入らない値。**
  - 訂正: ✅2026-09-07 回答＋対応 → **ご指摘のとおりで、地図が誤っていた。**
    濃さを決める式は「Print comparison marks **または** Always Show Marks on Target が ON なら選んだ濃さ、
    どちらも OFF なら不透明」。⚠**私はヘッダーのコメントを写したのだが、そのコメントが
    Always Show Marks on Target を落としていた**（コメント側も直した）

## 4. ★★いつ見えるか ―― 印の種類ごとに規則が違う

- **MK-11** **リングと相手なしの「/」**が画面に出るのは、次のどれかのとき。
  ① **ツールの左ボタンを押している間**（既定。押すと出て、離すと消える）
  ② **Print comparison marks が ON**（このときは常時表示になる）
  ③ **Always Show Marks on Target が ON**（★**画面だけ**）
  ④ サムネイル（第12章）
  - 訂正:

- **MK-12** ★★★**✓（Check）と猫の手は、この規則に従わない。** どちらも**画面では常に見えている**
  ―― トグルとも、ツールの左ボタンとも無関係。⇒ **「比較の印」と「読み手が残した印」は、見え方からして別物。**
  （それぞれの詳細は第5章。）
  - 訂正:

- **MK-13** **旧版の覗き見（peek）**も左ボタンの規則とは別で、**Shift＋左ボタン**（旧版を不透明で重ねる）と
  **Shift+Alt＋左ボタン**（50% で重ねる）。**押している間だけ**見え、離すと元に戻る。
  ★**Target と Source のどちらの窓からでも働く。** 詳しくは第13章。
  - 訂正: ✅2026-09-07 回答＋対応 → **ご指摘のとおりで、地図が誤っていた。**
    「ダブルクリック」と書いたが、**覗き見の入口にダブルクリックは1か所も無い**（実測0件）。
    ⚠**これもヘッダーのコメントを写したもの**で、そちらが「driven separately, by a double click」と
    書いたまま腐っていた（コメント側も直した）

## 5. Target と Source ― どこが同じで、どこが違うか

- **MK-14** ★**Target も Source も、常時表示のトグルが決めるのは「画面」だけ。**
  出力（印刷・PDF）に出るかどうかは、どちらの側も **Print comparison marks** が決める。
  ⚠**2026-09-07 まで Source 側だけが例外**で、自分のトグルだけで出力にも出ていた ――
  そのため「Print comparison marks は OFF」にしていても、Source 文書を刷ればマークが出た。
  ⇒ **1つのスイッチが2つのことを意味していたのをやめ、Target と同じ規則に揃えた。**
  - 訂正: ✅2026-09-07 回答＋実装 → ⚠**その実装は行き過ぎで、2026-09-08 に直しました。**
    あのとき出力の判定を「Source 側のトグル **かつ** Print comparison marks」にしましたが、
    それだと **Print を ON にしても「常に表示」が OFF なら出力に出ない** ―― **表示のスイッチが
    出力に拒否権を持つ**形になっていました（作者の指定「Print ON なら印刷可能、常に表示は
    あくまで常に表示するだけ」）。⇒ **出力は Print だけが決める**に統一（この規則文のとおり）。
    ★**同じ主張が7か所に書かれていた**ので 09-07 に全部直した
    ―― うち1つは**別経路**（印刷・PDF 用アドーンメントの「透明が生じるか」の申告）で、
    **そこを直さなければ片側だけ変わって食い違うところだった**。
    ⚠**この行はかつて「画面の振る舞いは1つも変えていない」で終わっていました** ―― それは 09-07 には
    正しく、**09-08 に変わりました**（下の MK-14b）。**「変えていない」と書いた文は、変えた日に
    嘘になるのに、変えた人は普通そこを読み返しません。**

- **MK-14b** ★★★**「Print comparison marks」は、画面にも出す**（2026-09-08）。
  ON にすると、**印刷・PDF・プリントプレビューに出る**うえに、**両方の文書の画面にも出続ける**。
  ⇒ **見えているものが、そのまま出てくる。**
  ★**Target 側は元からそうでした**（この条件が入っていた）。**Source 側だけが読んでいなかった**ので、
  Print を ON にすると片方の窓だけが光る、という状態になっていました。
  - 訂正: ✅2026-09-08 対応（作者の指定「Print ON なら印刷可能で常に表示される状態に、
    プリントプレビューにも表示。常に表示はあくまで常に表示するだけ」）。
    ✅**実機（トグル校正）** ―― Source 窓で **ON → 27,181 画素**が変化（ページ全体のリング）／
    **OFF → 残る差はタブ帯の 697 画素だけ**（文書名に付く `*` の増減で、ページ本体は1画素も残らない）

- **MK-15** ★★**オーバープリントプレビュー中は「印刷に出るものだけ」が見える。**
  Print comparison marks が **ON なら従来どおり出る**。**OFF なら、リング・「/」・✓・猫の手・
  ノンブル除外の塗りが、すべて消える。**
  ⇒ **刷り上がりを確かめている画面に、刷られないものを載せない。**
  ★**旧版の覗き見（Shift／Shift+Alt）だけは例外**で、そのまま使える ―― 押している間の確認であって、
  紙に載ると言い張っているものではないため。
  ⚠**2026-09-07 まで逆だった**（「オーバープリントプレビューは作業モードだから抑制しない」という
  2026-07-05 の判断）。
  - 訂正: ✅2026-09-07 対応（**コードを変更**）→ ご指示のとおりにした。
    ★判定は**オーバープリントプレビュー専用のビューポート属性**で行う ―― 描画フラグの `kPreviewMode` は
    **PDF 書き出しと同じビット**なので使えない（そこは 2026-07-05 に一度踏んで記録が残っていた）。
    ✅**ビルド済み・実機でも確認済み**（2026-09-07 夜・作者の手で）

- **MK-16** ★どちらのトグルも **Start は触らない**。設定はパネルと一緒に保存され、起動時に戻るので、
  比較のたびに上書きすると**保存した選択が消えてしまう**ため。
  - 訂正:

## 6. Story モードとの関係

- **MK-17** ★★★**Story 変更モードでは、リングだけが止まる。**
  相手なしの「/」・登録の緑「/」・✓・猫の手・覗き見・旧ノンブルのバッジは**そのまま出る**
  ―― これらは**ページの対応づけ**から来るもので、対応づけは**どちらのモードでも作られる**から。
  - 訂正:

- **MK-18** （**削除**。実装の書き方についての注意でしかなく、製品の決まりごとではなかった。
  言いたかったことは MK-17 に入っている。★番号は詰めない、という決まりに従ってここは空けておく。）
  - 訂正: ✅2026-09-07 対応 → **「これ何をいってるの？」というご指摘のとおり、読み手に意味のない項目だった。**
    「描画のコードは Story モードでも入口で引き返してはいけない」という**実装者向けの注意**を、
    そのまま規則として書いてしまっていた。⇒ 削除。★**この地図は「製品として何がどう決まっているか」を

## 7. ノンブルを除外した領域の塗り

- **MK-19** 「Ignore Page Number Marker」が ON のとき、**比較から外した矩形が緑で塗られる**
  （不透明度 **25%**）。⇒ **どこを見なかったか**が画面で分かる。
  ⚠**実装は面の塗りつぶし**で、枠線は引いていない（`rectfill` 1本）。
  ★**画面だけの表示**で、印刷にも PDF にも出ない（版面を覆ってしまうため）。
  - 訂正: ✅2026-09-07 回答＋**実装済み** → 呼び方を「網」から「塗り」に改め、**濃さを 35% → 25% に下げた**。
    ★もし画面で「枠」に見えているなら、それは塗りとは別の何かを見ている可能性があるので、知らせてください

- **MK-20** ★その塗りは、**その比較が実際に使った矩形**そのもの（第3章 CMP-21）。
  - 訂正: ✅2026-09-07 対応 → 「網」を「塗り」に直した（MK-19 と同じ）
