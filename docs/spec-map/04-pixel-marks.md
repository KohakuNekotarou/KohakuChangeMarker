# 04. Pixel のマーク ― 画面に何が出るか

## 1. 比較が生む印は2つ

- **MK-01** **変更リング** ―― 変わったところを囲む輪。Pixel 比較で「変わった」と判定されたページに出る。
  - 訂正:

- **MK-02** **あふれの「/」** ―― 相手のいないページ（組にできず、あふれたページ）に引かれる斜線。
  ★これは比較の結果として出るもので、**読み手が登録した「相手なし」**（緑の「/」・第5章）とは別。
  - 訂正:

- **MK-03** ★**この章の印はどれも文書を変えない。** 画面と出力に描いているだけで、ページアイテムは1つも作らない。
  - 訂正:

## 2. リングの形と太さ

- **MK-04** ★**リングは「変わったところ」ではなく、その縁を囲む。** 変わった領域そのものは塗らないので、
  **下の版面が見える**。
  - 訂正:

- **MK-05** 輪の太さは**画面上で一定**（8ピクセル）。★**拡大しても縮小しても同じ太さ**に見える
  ―― ズームを変えるたびに太さが変わると、変更の大きさと見分けがつかなくなるため。
  - 訂正:

- **MK-06** 変わった領域が近くに複数あると、輪は**つながって1つの形**になる（1つずつ丸で囲むのではない）。
  - 訂正:

## 3. 色と濃さ

- **MK-07** 色は**赤（既定）か シアン**の2択で、**読み手が選ぶ**（フライアウトの Mark colour）。
  - 訂正:

- **MK-08** ★★**かつては自動で決めていた**（赤っぽい地の上では自動でシアンに変えていた）が、**やめた**。
  理由は2つ ―― ①**Story モードの色地は下の地を読めない**ので、2つのモードで色の決まり方が食い違う
  ②**自動で変わると、見ている人にその理由を説明できない**。
  ⇒ **赤が地に紛れるなら、読み手がシアンを選ぶ。**
  - 訂正:

- **MK-09** 濃さは **25% と 75%** の2択（フライアウト）。**画面と印刷で同じ値**を使う。
  - 訂正:

- **MK-10** ⚠**ただし「常に表示」しているときだけは例外**で、印刷が OFF なら**不透明**で出る
  （画面でしか見えない印なので、薄くする理由がない）。印刷が ON なら選んだ濃さになる ―― そうしないと
  画面と刷り上がりが食い違ってしまうため。
  - 訂正:

## 4. ★★いつ見えるか ―― 印の種類ごとに規則が違う

- **MK-11** **リングとあふれの「/」**が画面に出るのは、次のどれかのとき。
  ① **ツールの左ボタンを押している間**（既定。押すと出て、離すと消える）
  ② **Print comparison marks が ON**（このときは常時表示になる）
  ③ **Always Show Marks on Target が ON**（★**画面だけ**）
  ④ サムネイル（第12章）
  - 訂正:

- **MK-12** ★★★**✓（Check）と猫の手は、この規則に従わない。** どちらも**画面では常に見えている**
  ―― トグルとも、ツールの左ボタンとも無関係。⇒ **「比較の印」と「読み手が残した印」は、見え方からして別物。**
  （それぞれの詳細は第5章。）
  - 訂正:

- **MK-13** **旧版の覗き見（peek）**も左ボタンの規則とは別で、ダブルクリックで出す（第13章）。
  - 訂正:

## 5. Target と Source は対称ではない

- **MK-14** ★★**「Always Show Marks on Target」は画面だけ、「Always Show Marks on Source」は画面と出力の両方。**
  この非対称は意図したもの ―― Target 側の出力は **Print comparison marks** が決めると決めてあるので、
  Target 側の常時表示が出力にも効いてしまうと、**Print comparison marks が意味を失う**。
  - 訂正:

- **MK-15** ⚠Source 側の常時表示は、**オーバープリントプレビュー中も隠れない**。
  - 訂正:

- **MK-16** ★どちらのトグルも **Start は触らない**。設定はパネルと一緒に保存され、起動時に戻るので、
  比較のたびに上書きすると**保存した選択が消えてしまう**ため。
  - 訂正:

---

## 6. Story モードとの関係

- **MK-17** ★★★**Story 変更モードでは、リングだけが止まる。**
  あふれの「/」・登録の緑「/」・✓・猫の手・覗き見・旧ノンブルのバッジは**そのまま出る**
  ―― これらは**ページの対応づけ**から来るもので、対応づけは**どちらのモードでも作られる**から。
  - 訂正:

- **MK-18** ⚠だから描画は「Story モードなら何もしない」とは書けない。**止めるのはリングだけ**で、
  ほかの印はモードに関係なく描かれる。
  - 訂正:

## 7. ノンブルを除外した領域の網

- **MK-19** 「Ignore Page Number Marker」が ON のとき、**比較から外した矩形に緑の網がかかる**
  （不透明度 35%）。⇒ **どこを見なかったか**が画面で分かる。
  - 訂正:

- **MK-20** ★その網は、**その比較が実際に使った矩形**そのもの（第3章 CMP-21）。
  - 訂正:
