## 1. これは何か

- **BK-01** ★★★**ブック比較が答えるのは「どの章が変わったか」だけで、「どこが変わったか」は答えない。**
  章（＝ブックに並んだ1つのドキュメント）ごとに、変わった／変わらないの**1ビット**を出す。
  作者の指定＝「ドキュメント単位で、変更あり／なしだけ見せる」「1つ見つかったらその章は終わり、次へ進む」。
  - 訂正:

- **BK-02** ★★**比較モード（Pixel / Story）とは無関係で、常に画素で比べる。** Story モードにしていても、
  ブック比較は本文差分をしない。⇒ **モードを切り替えてから実行しても結果は変わらない。**
  - 訂正:

- **BK-03** ★★★**文書比較（Start）とは完全に別の仕組み。** 指名（Target/Source）を変えず、比較を始めも止めもせず、
  マークも作らない。⇒ **比較中でもブック比較を実行できる**し、実行しても画面のマークは消えない。
  - 訂正:

- **BK-04** ⚠**ただし1つだけ道具を共有している** ―― ノンブルの位置を覚えておく表を、ブック比較は
  **測り直しながら**使う。章を1つ閉じるたびにその表は空になるので、**次に文書比較を始めたときは
  自分で測り直す**（結果は変わらないが、その1回だけ余分に測る）。
  - 訂正:

## 2. どの2冊を比べるか

- **BK-05** ★★★**Target ＝ ブックパネルで「前面のタブ」になっているブック**（新しい方）。
  **Source ＝ それ以外で最初に開いているブック**（古い方）。
  - 訂正:

- **BK-06** ★★★**InDesign の「アクティブなブック」は使わない。** アクティブブックはタブを切り替えても
  変わらず（章に触ったときだけ変わる）、見ているブックとずれる。
  ⇒ **前面タブが特定できないときは、代わりにアクティブブックを使う、ということを意図的にしていない。**
  ★KBS（検索）は同じ場面でアクティブブックへ落とすが、あちらは読むだけ。**比較は「どの2冊を比べたか」が
  意味のすべてなので、黙って別のブックを比べるくらいなら何もしない。**
  - 訂正:

- **BK-07** ⚠**3冊以上開いているときの Source は「最初に見つかった1冊」で、選び方に意味はない。**
  ⇒ そのために**両方のブックの名前を必ず画面に出す**（確認アラートと結果ダイアログの2か所）。
  - 訂正:

- **BK-08** ★★**名前ではなく、フルパスで示す。** 新旧2版は同じ仕事の2つの版なので**ファイル名が同じ**ことが多く、
  「a.indb と a.indb」では1冊を2回数えたようにしか読めない。
  - 訂正:

- **BK-09** ★**閉じかけのブックは相手にしない。** ブックの一覧に載っていることと、開いていることは別の質問なので、
  一覧に載っていても「開いているか」を重ねて聞く。
  - 訂正:

- **BK-10** ★**フライアウトの「Compare Books」は、2冊が決まらないときは灰色**（前面タブが無い・
  ブックパネルが閉じている／アイコン化している・ブックが1冊しか開いていない、のいずれか）。
  ★**灰色の判定と、押したときの処理は同じ手続きを通る**ので、見た目と結果が食い違わない。
  ⚠**ただし時間差はある** ―― メニューを組み立てた後に前面タブが変わりうるので、
  押したときにもう一度聞き直し、駄目なら**「ブックパネルでタブを前面にして、もう1冊開いてください」**と言って止まる。
  - 訂正:

- **BK-11** ⚠★**この機能の2つのアラートは言語が違う。** 実行前の確認は**どのロケールでも英語**、
  2冊が決まらないときの警告は**日本語 UI では日本語**。
  英語へ統一する指示が確認アラートだけを名指ししたため、片方だけが動いた。**揃えるかどうかは未決。**
  - 訂正:

## 3. 実行の手順

- **BK-12** ★★**順番は「メニュー → 確認アラート → OK で比較 → 結果ダイアログ」。**
  ⇒ **ダイアログは答えが入った状態で開く。** 以前はダイアログが先に空で開き、中の Compare ボタンを押す形だった
  （作者の指示で逆にした。ボタンはその時に無くなった）。
  - 訂正:

- **BK-13** ★**確認アラートで Cancel を押すと、何も起きない。** 章を開くのはアラートの後なので、
  取り消すものが何も無い。
  - 訂正:

- **BK-14** ⚠**アラートに出るパスの「&」は消えない。** アラートの文字列はメニュー項目と同じ扱いを受けるので、
  `Q&A` というフォルダ名は素のままだと `QA` と出る。⇒ 二重にしてから渡している。
  ★**ウィジェットに入る文字列（ダイアログの2行）は資源側で同じ機能を切ってあるので、そちらは通していない。**
  - 訂正:

- **BK-15** ★**アラートのパスは省略されない。** 幅の合わないパスはアラートを横に広げる。
  ⇒ **「この2冊で合っていますか」に答えるには、省略しない方が良い**という判断。
  - 訂正:

- **BK-16** 比較が終わるまで操作は戻らない。**待っている間は進捗バーが出て、いま見ている章の名前が出る**（BK-30）。
  - 訂正:

## 4. 章の対応づけ

- **BK-17** ★★★**章は「並び順」で組にする。** ブックの1番目どうし、2番目どうし……。
  **ファイル名は照合しない**（作者の指定）。
  ⇒ **章を改名しても組はずれない**が、**途中に1章挿入すると、それ以降が全部ずれる。**
  - 訂正:

- **BK-18** 章の数が違うときは、多い方の余りが**そのまま答えになる** ―― Target にだけあれば
  **ChapterAdded**、Source にだけあれば **ChapterDeleted**。**この2つは1ページも開かずに決まる。**
  - 訂正:

- **BK-19** ★**行に出す章の名前は Target 側のもの。** Source にしかない章だけ、そちらの名前を使う。
  （変更ページの TSV 書き出しがページに対して使っているのと同じ規則。）
  - 訂正:

- **BK-20** ★★**ブックの位置1つにつき、必ず1行できる。** 読めない章があっても行を落とさない。
  ⇒ 落とすと①以降の対応づけが1つずつずれ②理由を聞くときの番号も別の章を指す。
  ★**名前が取れなかった章は「(chapter 3)」のように位置で名乗る**（位置だけは必ず分かる）。
  - 訂正:

- **BK-21** ★**ブックがその章のファイルを言えないときは、開く前に Failed と決まる**（理由＝`no file in the book`）。
  ⚠**ただし片側にしか無い章（Added / Deleted）は上書きしない** ―― あれは既に出ている答えであり、
  もともと開く予定が無かったものを「開けなかった」と言い換えることになるため。
  - 訂正:

## 5. 1つの章をどう判定するか

- **BK-22** ★★★**章は1組ずつ開いて、判定して、閉じる。** 全部先に開くことはしない。
  ⇒ **同時に開いている章は多くても2つ**（閉じられなかった章を除く）。
  - 訂正:

- **BK-23** ★★**既に開いている章は、開いたままの状態で使い、こちらでは閉じない。**
  人が開いたものを閉じるのは驚かせるだけなので。
  - 訂正:

- **BK-24** ⚠★★★**「開いたままの状態」には、まだ保存していない編集も含まれる。**
  画面に出ている章は**画面のとおりに**比べられ、相手はディスクから読まれる。
  ⇒ **メモリの中にしかない編集で「変更あり」と出ることがある。**
  これは「いまこの章は相手と違うか」への正しい答えで、「ディスク上の2冊は違うか」への答えではない。
  **どちらを聞きたいかは実装からは分からない**ので、揃えたいなら**先に保存する**。
  - 訂正:

- **BK-25** ★**比較のために開く章は、窓を作らず、ダイアログも抑える。**
  ⇒ フォント欠落やリンク切れの警告で止まらない。★**本体のブック用の「開く」は使っていない**
  （あれは UI を抑えられないので、警告を出す章がそのまま失敗になり、章ごと結果から消える）。
  - 訂正:

- **BK-26** ★★**開けなかった理由は、ブック自身に聞く。** `missing` / `out of date` / `in use` / `open` の4語。
  ⇒ 「削除された」「他の人が開いている」「新しい版で保存された」を**同じ言葉にしない。**
  ★**聞くのは失敗したときだけ**なので、全部開ける実行には一切の負担がない。
  ★ブックが何も言わないときだけ `could not open` と出る。
  - 訂正:

- **BK-27** ★★**開いた直後の章は、組版が終わっていないので、必ず組み終えてから画素を読む。**
  ⇒ これをしないと**中身が同じ2章が違って見える。** ★文書比較（Start）がこれを要らないのは、
  あちらが「人が画面に開いている文書」しか読まないから。
  - 訂正:

- **BK-28** ★★**章を汚さない。** 組版もラスタ化も文書に触るので、**入る前が汚れていなければ、出た後も汚れていない**
  ように戻す。⇒ **「保存しますか」と聞かれずに閉じられる**（UI を抑えて閉じるので、聞かれたら中身が黙って失われる）。
  - 訂正:

- **BK-29** ★★★**判定は3段階で、どの段階でも早く終わる:**
  ①**ページ数が違えば、それだけで Changed**（1ページもラスタ化しない）
  ②ページの中は**最初の1画素が違った時点で**そのページの答え
  ③**最初に違ったページで、その章は終わり**（残りのページは読まない）
  ⇒ **最後まで読まれるのは「変わっていない章」だけ。**
  - 訂正:

- **BK-30** ★**ページも並び順で対応する**（1ページ目と1ページ目……）。
  - 訂正:

- **BK-31** ★★**ラスタ化の条件は文書比較とまったく同じ**（144dpi・CMYK・アンチエイリアスなし・
  小さい文字も字形を描く・**非印刷指定のものは描かない**）。
  ⇒ 印刷されないもの（作業メモ・刷版への指示）を動かしただけでは変更にならない。
  - 訂正:

- **BK-32** ★★★**ノンブル（自動ページ番号）の場所は、常に比較から外す。**
  文書比較にはこれを外すかどうかのトグルがあるが、**ブック比較にトグルは無く、必ず外す。**
  理由＝**章を1つ入れると、それ以降のノンブルが全部ずれる**ので、外さなければ以降のページが丸ごと変更扱いになる。
  ★**「ノンブルとは何か」を判定する部分は文書比較と共有**しているので、2つの答えが食い違うことはない。
  - 訂正:

- **BK-33** ★**ページを比べられなかったとき**（大きさが違う・画素が取れない）**は Failed で、理由は「page 7」のように
  ページ番号だけ。** 「変更なし」には決してしない。
  - 訂正:

- **BK-34** ★**この実行が開いた章だけを、判定の直後に閉じる。** 閉じられなかったものは
  要約行の **left open** に数える ―― 窓が無いまま `.indd` を掴み続けるので、人が閉じる手段がないため。
  ⚠**「閉じ始められた」までしか分からない**ので、この数は**少なく出ることはあっても多くは出ない**。
  - 訂正:

## 6. 進捗と中断

- **BK-35** ★**進捗バーはすぐ出る**（文書比較のように「3秒待ってから」ではない）。
  理由＝ブック比較は**必ず時間がかかる**（章ごとに開いて組んでラスタ化する。小さい章でも1章あたり 0.2 秒ほど）。
  - 訂正:

- **BK-36** バーは**いま開こうとしている章の名前**を出す（終わった章ではなく、待っている章）。
  ★章の中はページ数で割って進むので、**ページの多い章でも針が止まらない。**
  - 訂正:

- **BK-37** ★**章を開く前・ページの境目・そして全部終わった後に、もう一度**中断を確認する。
  ⇒ ①**次の章を開かせない**（開いて組むのが一番高い）②**最後の章の途中で押した中断も拾える。**
  - 訂正:

- **BK-38** ★★★**中断しても、そこまでに出た答えは残る。** 見ていない章は **NotCompared** になり、
  **NoChange に混ぜない** ―― 「調べられなかった」と「調べたが変わっていなかった」を同じ言葉にしないため。
  ★**章の途中で中断した場合もその章は NotCompared**（比べ終えたページは同じでも、残りは読んでいない）。
  - 訂正:

- **BK-39** ★**中断しても、この実行が開いた章は閉じる。** 中断が止めるのは比較であって、後片づけではない。
  - 訂正:

## 7. 結果の読み方

- **BK-40** ★★**答えの語は6つ**＝`Changed` / `NoChange` / `ChapterAdded` / `ChapterDeleted` / `Failed` / `NotCompared`。
  ★**英語のまま翻訳しない**（結果の語彙であり、テストのスクリプトがそのまま読み取るため）。
  - 訂正:

- **BK-41** ★★★**要約行は必ず章の数を先に言う。**「3 chapters: 1 changed, 2 unchanged」。
  ⇒ **一覧が空でも「全章を見て、変わったものが無かった」と読める**（「1つも開けなかった」と読み違えない）。
  - 訂正:

- **BK-42** ★**0 のものは書かない**、**前置きも付けない**。
  ⚠これは見た目の話ではなく**測って直したもの** ―― 要約行は真ん中を省略する1行なので、長くなると
  **数字の真ん中が落ちて、別の数字に見える**（「15 chapters」が「5 chapters」に読めた）。
  ⇒ **省略される場所を動かすのではなく、行そのものを短くした。**
  - 訂正:

- **BK-43** ⚠**`left open` だけは章数の内訳ではない**（1章につき最大2つ数えるので、足しても章数にならない）。
  他の6つの答えは足すと必ず章数になる。
  - 訂正:

- **BK-44** ★**中断した実行は、行末に「- cancelled」と付く**（読点ではなくダッシュ＝行全体にかかる断り）。
  ⚠**最後の章が終わった瞬間に押された場合は、「not compared」が1つも無いまま cancelled だけが付く。**
  - 訂正:

- **BK-45** ★★★**一覧には「変わっていない章」を出さない**（作者の指定）。出るのは
  Changed / ChapterAdded / ChapterDeleted / Failed / NotCompared。
  ★**数は要約行が全部から数えている**ので、一覧が空でも意味が読める。
  ★**Failed と NotCompared は必ず残す** ―― まだ答えの出ていない章であり、「変更なし」の反対だから。
  - 訂正:

- **BK-46** **1行は2つの欄**＝左に章のファイル名、右に答えの語。
  ★Failed の行だけ、左の欄に「 - 理由」が続く。
  - 訂正:

- **BK-47** ⚠★★**理由の文には「開けなかった」と書かない。** 隣の欄に必ず `Failed` と出ているので、
  同じことを2度言うと**行の幅を無駄に使う**。
  ⚠**これは節約の話ではなく、幅が実際に足りない** ―― 左の欄は**真ん中を省略する**（ファイル名用の設定）ので、
  理由を足すと**ファイル名の拡張子が省略される位置に移る**。
  実測＝「ch3.indd - could not be opened (missing)」が **「ch3.ind...ould not be opened (missing)」**と描かれ、
  **存在しないファイル名を名乗り、理由も両端が読めなくなった。** ★セルはツールチップも出さない設定なので、
  画面から読み直す手段が無い。⇒ **足すものは、ファイル名と並べて約38文字に収まること。**
  - 訂正:

- **BK-48** ★**一覧に「該当なし」の行は作らない。** Story Edits の一覧は空のときに「No edits」という行を作るが、
  こちらは**要約行が言葉で説明している**ので、行を発明しても読むものが増えるだけ。
  - 訂正:

- **BK-49** ★★**スクリプトからは全章が読める**＝`app.kcmBookResult`。1行1章で「名前 TAB 答え」、
  Failed の行だけ「TAB 理由」が続く。★**一覧と違って NoChange の章も含む**。
  ★**パネルが無くても答える**（比較をスクリプトから走らせて、画面を見ずに読めるように）。
  - 訂正:

## 8. 行から何ができるか

- **BK-50** ★**シングルクリックは選択するだけ**（何も開かない）。
  ★Story Edits の行はシングルクリックで飛ぶが、こちらは**開く**ことになるので二段構え。
  クリックが逸れて文書が開いてしまうと、クリックし直しでは取り消せない。
  - 訂正:

- **BK-51** ★★**ダブルクリック＝その章の Target 側と Source 側を、両方とも窓付きで開く**（作者の指定）。
  1行は「この章は変わった」という**組についての言明**なので、開くのも組。
  ★**片側しか無い章は片側だけ開く**（それは失敗ではない）。
  - 訂正:

- **BK-52** ★**Target を最後に開く**ので、**前面に残るのは Target**。
  - 訂正:

- **BK-53** ⚠★**ここで開くのは、比較のときとは正反対の開き方**＝**窓を作り、UI も抑えない。**
  ⇒ フォント欠落やリンク切れの警告は**出る**（人が見ているところで開いているのだから、出るべき）。
  ★**ここで開いた文書を、このプラグインが閉じることはない。**
  - 訂正:

- **BK-54** ★★**既に開いている章は、前面に出す。** 窓が無い状態で開いている章には**窓を作る。**
  ⇒ 「N documents open」は**人が実際に見られる窓の数**。
  ⚠**窓なしで開いたままの章は実際に起こりうる**（ブック比較が閉じ損ねた章＝BK-34）。
  - 訂正:

- **BK-55** ★★**右クリック＝行のメニュー。項目は「Start Change Marker」の1つだけ。**
  **Changed の行でしか有効にならない**（作者の指定）。
  ⇒ ChapterAdded / ChapterDeleted（相手がいない）・NoChange（印が1つも出ない）・
